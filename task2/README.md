# InfoVis dashboard — Task 2

The prepared InfoVis data and figures are included in this repository. **No additional data download or preparation step is needed to run Task 2.**

For the combined assignment landing page and both dashboards, follow the setup instructions in the repository root `README.md` and run `python main.py` from the repository root. Choose **Task 2 — InfoVis** on the landing page.

The dashboard includes:

- A directed clickstream network with Spring, Kamada–Kawai, and ForceAtlas2 layouts.
- Redfin parallel coordinates with brushing, filtering, and edge bundling.
- Zoomable treemaps with selectable area measures and hierarchies.
- Horizon and ridgeline plots for monthly housing trends and grouped distributions.
